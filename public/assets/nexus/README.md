# Nexus a lápiz

Los antiguos PNG se sustituyeron por `../sketch/nexus.webp` (cuatro poses registradas).
La referencia del usuario define cabeza marfil, máscara de grafito, ojos amarillos,
antenas naranja/azul, sudadera turquesa con el número 2, pañuelo naranja,
mochila marfil y cable lima. Las poses se extraen en `nexusAssets.ts` sin perder alfa.
Los adornos están en `../sketch/extras.webp`; se conserva la personalización guardada.
