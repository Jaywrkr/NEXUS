# Plaza a lápiz

La dirección de arte de bosquejo sustituye la muestra anterior de la plaza.
Todas las imágenes están en `../sketch/`: siete barrios y museo, siete habitantes,
aves, plantas y máquinas con estados. `src/art/plazaAssets.ts` mantiene únicamente
las claves de textura que usan las animaciones existentes, compuestas con estos dibujos.
No quedan activos los antiguos fondos y accesorios con acabado 3D.
